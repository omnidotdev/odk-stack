# Omni Development Kit (ODK)

Define your data model once. Generate OpenAPI, Protobuf, Drizzle ORM, JSON Schema, and more.

## Services

| Service | Description |
|---------|-------------|
| [odk](https://github.com/omnidotdev/odk) | Core SDK (Rust CLI, schema IR, plugin SDKs, TypeScript SDK) |
| [odk-site](https://github.com/omnidotdev/odk-site) | Marketing website |

## Getting Started

1. Copy configuration template:

   ```sh
   cp services.yaml.template services.yaml
   ```

2. Start development:

   ```sh
   tilt up
   ```

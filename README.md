# Omni Development Kit (ODK)

Omni Development Kit (ODK) is a tool that lets you model your data in one place; one source of truth, and generate artifacts from it for many different scenarios (validation schemas, API schemas, ORM schemas, client/server SDKs, CLIs, JSON Schema, ...)

## Local Development

Install dependencies:

```sh
bun install
```

Compile types:

```bash
# compile once
bun compile

# or watch mode
bun compile:watch
```
